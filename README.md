
# Morse Code Decoder

##  Project Overview

The Morse Code Decoder is a digital logic circuit-based project designed to convert Morse code inputs into their corresponding alphabetic characters.

The system accepts dots (0) and dashes (1) through push buttons. Using sequential logic and decoding circuits, the entered Morse code is processed and the corresponding alphabet is displayed on a 7-segment display.

This project was developed as a six-member group project as part of our Digital Logic Design coursework.

##  Objectives

- To understand the fundamentals of digital logic design.
- To implement Morse code decoding using logic gates and sequential circuits.
- To understand the applications of flip-flops, counters and shift registers.
- To convert binary input sequences into meaningful character outputs.

##  Prototype Specifications

Our initial prototype is designed to recognise and display four alphabets:

- A
- O
- S
- Y

The design can be further expanded to support additional alphabets.

##  Hardware Components Used

- NOR Gates
- AND Gates
- OR Gates
- D Flip-Flops
- Shift Registers (if used)
- Push Buttons
- Resistors
- LEDs
- 7-Segment Display
- Connecting Wires

##  Working Principle

1. The user enters Morse code using dot and dash push buttons.
2. The input sequence is stored using sequential logic circuits.
3. The stored binary sequence is processed by the decoding logic.
4. The corresponding alphabet is identified.
5. The output is displayed on the 7-segment display.

##  Future Improvements

- Expanding the decoder to support all 26 English alphabets.
- Improving the input mechanism.
- Adding support for numbers and special characters.
- Implementing a more advanced display system.
